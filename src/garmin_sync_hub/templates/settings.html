Profile

Used to estimate calories burned. The Keytel formula uses your weight, age, heart rate, and VO2max to compute kcal burned during each workout.

Used in calorie formula. Auto-filled by "Pull from Garmin".
How are calories calculated?
kcal/min = (-95.7735 + 0.634 × HR + 0.404 × VO₂max + 0.394 × Weight + 0.271 × Age) / 4.184
HR = Garmin watch or default 90 bpm VO₂max = {{ config.get('user_profile', {}).get('vo2max', 45) }} Weight = {{ config.get('user_profile', {}).get('weight_kg', 80) }} kg Age = from birth year {{ config.get('user_profile', {}).get('birth_year', 1990) }}

Based on the Keytel et al. (2005) prediction equation. HR comes from Garmin daily monitoring if available, otherwise defaults to 90 bpm. The rate is multiplied by workout duration to compute total kcal.

Heart Rate Data

When enabled, your Garmin daily heart rate data is fetched and overlaid on workout charts — showing your actual HR during each exercise with color-coded segments. This requires a Garmin watch or HR monitor that records to Garmin Connect. Data is cached locally after first load.

Update Existing Activities

When enabled, syncing will check if a matching activity already exists on Garmin (by start time) and update it with the Liftosaur data instead of creating a duplicate. Disable this to always create new activities.

Activities within this many minutes of the workout start time are considered matches.

Copy elsewhere (rclone)
After each backup, new files are copied to Google Drive, OneDrive, Dropbox, a NAS (SFTP, SMB) or S3 with rclone. Set up the connection once on the server: docker compose exec garmin-sync-hub rclone config --config {{ rclone_config }} For Google Drive, choose the full access scope (drive) so an existing folder is used, answer “n” to auto config and follow the link it gives. Nothing is deleted at the destination. Test lists the folders rclone sees and warns about duplicates.
remote:folder, the remote being the name you gave in rclone config. Empty: no copy.

How it works
Each rule gives a dog to the activities whose name matches it. With auto-scan on, the app checks your new activities at its interval (and your whole history with Check now on the Dogs page): an activity missing its dog shows up as Not synced. Sync adds the dog by sending back the activity's metadata with the dog added: dogs already on it and everything else are kept. Restore removes only the dogs this app added, and automatic runs then leave that activity alone.
