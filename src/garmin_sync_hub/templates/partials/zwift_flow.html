How it works

{% if cfg.auto_scan %}Auto-scan looks for pairs every {{ cfg.scan_interval_minutes|interval_label }}, back to the last scan that worked (3 days of margin){% else %}Auto-scan is off: pairs are looked for when you click Check now{% endif %}; Check now reads the whole history. What a scan finds is {% if cfg.auto_merge %}merged right away (auto-sync is on){% else %}listed as not synced until you click Merge (auto-sync is off){% endif %}. Each watch point gets the Zwift position closest in time (within {{ cfg.time_tolerance_s }} s); everything else in the watch file is kept. Nothing is deleted before the merged activity is on Garmin. Backups stay in data/zwift_backups.
