How it works

Watch activity on Garmin, no map

Kept exactly as recorded:
  • heart rate, power, cadence, footpod
  • laps, time, distance, device
  • name, description, type, gear
+

Zwift copy same ride or run

Found on Garmin{% if zwift_connected %}, in your Zwift account{% endif %}, or in a FIT file you upload. Gives only:
  • the GPS track (the Zwift map)
    • {% if cfg.copy_altitude %}
  • the virtual altitude
    • {% else %}
  • not the altitude (off in settings)
    • {% endif %}

Merged activity on Garmin

  • all the watch data, plus the map
  • name, description, type and gear restored
  • replaces the watch activity
    • {% if cfg.delete_source %}
  • the Zwift copy is deleted
    • {% else %}
  • the Zwift copy is kept (off in settings)
    • {% endif %}
  1. Pair: {% if cfg.auto_scan %}every {{ cfg.scan_interval_minutes }} min{% else %}when you click Scan now{% endif %}, activities from the last {{ cfg.scan_days }} days are matched when they overlap by at least {{ (cfg.min_overlap * 100)|round|int }}%. Each watch point gets the Zwift position closest in time (within {{ cfg.time_tolerance_s }} s).
  2. Check (optional): Simulate builds the file without touching Garmin; Preview shows its map and charts.
  3. Merge: {% if cfg.auto_merge %}automatic for every pair found{% else %}only when you click Merge{% endif %}. The merged file is uploaded first; the old activities are deleted only once it is on Garmin. Backups stay in data/zwift_backups.
