Where it goes
  • Folder on the server: {{ root }}{% if root|string == "/backup" %} (the ./garmin-backup folder next to docker-compose.yml){% endif %}.
  • {% if s.rclone_remote %}Copied after each backup to {{ s.rclone_remote }} with rclone.{% else %}Not copied elsewhere. Google Drive, OneDrive, Dropbox, a NAS… can be added in Settings → Backup.{% endif %}
  • As a zip file, with the button above.
What is saved
  • activities/: every activity as the file Garmin keeps (FIT for watch activities), sorted by category and year, plus Garmin's summary (.json) and index.csv. Re-import a file in Garmin Connect with Import Data.
  • account/: profile, settings, devices, personal records, goals, heart rate zones.
  • gear/: all your gear, active and retired, with its totals (distance, time), its default activity types and the activities it was used in.
  • workouts/ and courses/: as FIT files (and GPX for courses).
  • history/: one file per year for the calendar, body composition, weigh-ins, blood pressure, endurance and hill scores, race predictions.
  • health/{% if not s.health %} (off in Settings){% endif %}: one file per metric and per day (daily summary, sleep, HRV, heart rate, stress, Body Battery, steps, SpO2, respiration, training readiness, VO2 max, weight…){% if s.health_since %} since {{ s.health_since }}{% else %} since your first activity{% endif %}, plus daily_summary.csv.

A file already saved is never downloaded again, so each run only adds what is new. The first run is long: Garmin limits how fast data can be read, and an interrupted run resumes where it stopped.
